Bilingual Voice Assistant - Icon Pack
========================================
This directory contains production-ready icons in all required Chrome Web Store
and high-DPI display resolutions:

- icon16.png   : 16x16   (Browser favicon, extension toolbar icon)
- icon24.png   : 24x24   (Standard Chrome extension action icon)
- icon32.png   : 32x32   (Windows high-DPI taskbar / display)
- icon48.png   : 48x48   (Chrome Extension management page: chrome://extensions)
- icon64.png   : 64x64   (High-DPI display / Side panel)
- icon96.png   : 96x96   (Retina high-DPI display)
- icon128.png  : 128x128 (Chrome Web Store installation icon)
- icon256.png  : 256x256 (High-resolution promotional banner / desktop)
- icon512.png  : 512x512 (Chrome Web Store Developer Dashboard store asset)

All icons are pre-rendered with anti-aliasing, RGBA alpha transparency, and compliant with Chrome Web Store guidelines.
